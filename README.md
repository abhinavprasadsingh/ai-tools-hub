# AI Tools Hub

A beginner-friendly AI tools website built using HTML, CSS and JavaScript.

## Features

- Responsive homepage
- Tool directory
- Live tool search
- Mobile navigation
- About page
- Contact page interface
- Privacy policy page
- Custom favicon

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub (planned)
- Cloudflare Pages (planned)

## Run locally

Open PowerShell in this directory and run:

py -m http.server 5500

Open http://localhost:5500 in your browser.
